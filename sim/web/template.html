Run your own firmware

        

          
Your Pico SDK C files compile unchanged against a simulated SDK. tools/sim.mjs compiles a firmware folder and opens this view with it loaded. You can also load a .wasm here with Firmware → Load your .wasm….

        

        
cd rp2350-card-sim
npm install            # once: Binaryen, three.js
brew install llvm lld  # once: clang + wasm-ld
export PATH="$(brew --prefix llvm)/bin:$(brew --prefix lld)/bin:$PATH"
node tools/sim.mjs path/to/your/firmware   # compile + open in 3D
node tools/run-headless.mjs my-fw.wasm     # text report, no browser

        

          
Supported: gpio_* (incl. masked), i2c_*, sleep/busy_wait, timers and alarms, GPIO IRQs, multicore_*, mutexes, spin locks, printf. Direct register writes (sio_hw->…), PIO and DMA are not simulated; an unsupported call fails at link time with its name.

          
Compute time comes from an instruction count with Cortex-M33 costs. Double-precision maths is charged as software-emulated, as on the real chip.
